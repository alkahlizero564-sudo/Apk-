# Alpha — مصنع التطبيقات المتكاملة

**Alpha** تطبيق Flutter يبني تطبيقات أندرويد كاملة بخمس لغات — **HTML و PHP و Flutter و Python و Kotlin** —
تطبيقاً واحداً أو **تطبيقين متصلين** (عميل + إدارة)، مع قاعدة البيانات والجداول والصلاحيات والإشعارات بينهما
على **Supabase** أو **Firebase**، تلقائياً.

## كيف يعمل

```
Alpha (على هاتفك)                    هذا المستودع (GitHub)                     النتيجة
──────────────────                   ─────────────────────                     ───────
تصميم + جداول + سيرفر  ── commit ──▶  apps/<app>/alpha.json                    APK موقّع
                                      projects/<p>/schema.sql   ── Actions ──▶  (إصدار GitHub)
                                      engines/<lang>/  (محرّكات مختبرة)          + السيرفر جاهز
```

1. في Alpha تختار اللغة، التصميم (قوالب ألوان، داكن/فاتح، زجاجي/ناعم/مسطّح، استدارة) مع **معاينة حيّة**،
   والجداول (قوالب جاهزة: متجر، مطعم، عيادة، حجوزات، مدرسة، توصيل… أو **يصمّمها الذكاء الاصطناعي** من وصفك).
2. Alpha يكتب كل الملفات في المستودع بـ **commit واحد** (لا ملفات ناقصة أبداً).
3. **تجهيز السيرفر** (`backend.yml`): ينفّذ SQL على Supabase (أو قواعد Firestore)، يفعّل تسجيل الدخول،
   يسجّل التطبيقات في Firebase، وينشر دالة الإشعارات — ثم يكتب الاتصال في كل تطبيق.
4. **البناء** (`build.yml`): يجهّز المشروع من المحرّك، يفحصه، يصلح كود الذكاء الاصطناعي تلقائياً إن فشل،
   يوقّعه بمفتاح دائم (كل بناء يُثبَّت كتحديث)، وينشر الـ APK.

## لماذا بدون أخطاء

- **محرّك مختبر لكل لغة** (`engines/`): تطبيق كامل يُبنى من وصف الجداول — تسجيل دخول، قوائم، بحث، فلاتر،
  إضافة/تعديل/حذف، لوحة إحصاءات للإدارة، إشعارات، Push. لا يحتاج كتابة كود ولا ذكاء اصطناعي.
- **SQL يُولَّد بشكل حتمي** (`lib/generator/sql_generator.dart`) وليس بالذكاء الاصطناعي، ومختبر على PostgreSQL حقيقي:
  كل القوالب تُنفَّذ مرتين (آمن لإعادة التشغيل) واختبار صلاحيات كامل (`factory/test/rls_test.sql`).
- **المكتبات بإصدارات مثبّتة ومختبرة معاً** (`factory/libraries.json`) — الذكاء الاصطناعي لا يستخدم غيرها.
- **فحص قبل البناء**: HTML يُفتح في Chrome ويُضغط على كل التبويبات، PHP يُشغَّل ويُطلب كل صفحة،
  Flutter `analyze`، Python `py_compile`، Kotlin `gradle` — والذكاء الاصطناعي يصلح الكود المخصص إن فشل.
- `alpha.yml` يختبر كل شيء عند كل تعديل: تطبيق Alpha، المحرّكات بكل اللغات والسيرفرات (`factory/selftest.py`)، وقاعدة البيانات.

## قاعدة البيانات والصلاحيات (تلقائياً)

لكل مشروع بادئة `<p>_` (عدة مشاريع في مشروع Supabase واحد):

| الجزء | ما يُنشأ |
|---|---|
| الحسابات | `<p>_profiles` (role: customer/admin)، `<p>_admins` (بريد المديرين)، حماية من ترقية النفس لمدير |
| أنواع الجداول | **كتالوج** (الكل يقرأ، الإدارة تكتب) · **خاص بالعميل** (كل عميل يرى صفوفه فقط) · **مشترك** · **إدارة فقط** |
| الأعمدة | أنواع (نص، رقم، سعر، تاريخ، صورة، هاتف، بريد، اختيار…)، مطلوب، فريد، قيمة افتراضية، **حقول للإدارة فقط** (مثل حالة الطلب) |
| الإشعارات | طلب جديد ← الإدارة · تغيير الحالة ← صاحب الطلب · منتج جديد ← كل العملاء، مع Push عبر FCM |
| أخرى | Realtime، `<p>_stats()` للوحة الإدارة، `updated_at` تلقائي، تسجيل أجهزة الإشعارات |

مع Firebase: قواعد أمان Firestore بنفس المنطق + Cloud Function للإشعارات.

## اللغات والمكتبات

| اللغة | التشغيل | البيانات | Push |
|---|---|---|---|
| HTML | Capacitor 8 + 16 مكتبة مدمجة (Tailwind، Chart.js، Alpine، Bootstrap RTL، Swiper، Leaflet…) | جهاز / Supabase / Firebase | ✓ |
| PHP | سيرفر PHP 8.3 (+ Dockerfile) و APK يفتحه | SQLite على السيرفر / Supabase | — |
| Flutter | Flutter stable + 37 حزمة مختبرة | جهاز / Supabase / Firebase | ✓ |
| Python | Flet 1.0.5 | جهاز / Supabase | — |
| Kotlin | Jetpack Compose (Material 3) | جهاز / Supabase | ✓ |

القائمة الكاملة في تبويب **المكتبات** داخل Alpha أو في `factory/libraries.json`.

## الإعداد (مرة واحدة)

1. ثبّت Alpha (من الإصدارات: `alpha-v…`).
2. **الإعدادات > GitHub**: توكن بصلاحيات repo و workflow، والمستودع (هذا المستودع).
3. اختياري: **الذكاء الاصطناعي** (Claude / Gemini)، **Supabase** (Access Token + اختيار المشروع)،
   **Firebase** (Service Account JSON). Alpha يحفظها مشفّرة كـ Secrets في المستودع.

## هيكل المستودع

```
lib/                 تطبيق Alpha (Flutter)
  generator/         SQL، قواعد Firestore، ملفات المشروع، القوالب
  ui/screens/        الرئيسية، المعالج، استوديو التصميم، استوديو البيانات، البناء، المكتبات، الإعدادات
engines/<lang>/      المحرّك المختبر لكل لغة
factory/             سكربتات GitHub Actions: prepare، backend_setup، ai_code، sign، selftest
.github/workflows/   alpha (اختبار وبناء Alpha)، build، backend، generate
apps/<app>/          تطبيقاتك (alpha.json + custom/ لكود الذكاء الاصطناعي)
projects/<p>/        مشاريعك (schema.sql، firestore.rules، project.json)
```

> المفتاح الدائم للتوقيع يُنشأ في `signing/` عند أول بناء — اجعل المستودع **خاصاً**، أو ضع المفتاح في
> Secret باسم `ALPHA_KEYSTORE_B64` (+ `ALPHA_KEYSTORE_PASSWORD`).
